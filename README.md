# SQL Practice & Data Quality Validation

Bienvenido/a a mi repositorio de práctica de SQL enfocado en **Análisis de Datos, Ingeniería de Datos y Calidad de Información (Data Quality)**.

## Objetivo del Proyecto
Demostrar capacidades prácticas para consultar, filtrar, transformar y validar bases de datos relacionales, asegurando la integridad de los datos antes de su análisis o consumo en dashboards.

##  Tecnologías y Conceptos Aplicados
* **Lenguaje:** SQL (ANSI SQL / PostgreSQL / MySQL)
* **Conceptos clave:** 
  * Filtrado y Agregaciones (`WHERE`, `GROUP BY`, `HAVING`)
  * Uniones de tablas (`INNER JOIN`, `LEFT JOIN`)
  * Detección de duplicados y nulos (Data Quality)
  * Funciones condicionales (`CASE WHEN`)

## Estructura del Repositorio
* `01_Data_Quality_and_Validation/`: Scripts diseñados para auditar y limpiar bases de datos relacionales.
  * `01_data_cleaning_and_validation.sql`: Ejercicios de detección de registros inválidos, nulos y duplicados.
